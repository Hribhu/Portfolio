# Varun Shah — Portfolio

**Signal to Insight** — a personal portfolio site for Varun Shah, an Electronics & Telecommunication Engineer turned Data & Full-Stack Builder. The design theme runs through the whole site: raw signal resolving into structured insight.

Built with plain HTML, CSS and JavaScript — no frameworks, no build step.

---

## ✨ Features

- **Animated loading screen** — the name types itself out with a blinking caret and a progress bar before fading into the site.
- **Typewriter headings** — every section heading types itself out as it scrolls into view, then settles into a slow amber/teal shimmer.
- **Signal-to-bar canvas animation** — a custom `<canvas>` piece in the hero that morphs a raw waveform into discrete data bars, representing the site's core thesis.
- **Broadcasting signal tower** — an SVG lattice tower with a pulsing beacon and expanding radio-wave rings, a nod to the ECE background.
- **Live "solar system" background** — small planets orbit continuously behind the content at different speeds, sitting on top of a fixed marble background.
- **Scroll-reveal animations** — timeline items, project cards, skill bars and stats fade/slide in as they enter the viewport (`IntersectionObserver`).
- **Skill bars** — generated dynamically from `data-level` attributes, no hardcoded markup per skill.
- **Fully responsive** — dedicated breakpoints down to small phones and landscape orientation; decorative elements (tower, cursor glow) hide gracefully on small screens.
- **Accessible by default** — respects `prefers-reduced-motion`, visible focus states, semantic sectioning.
- **Icon-linked contacts** — LinkedIn, GitHub and Email are wired up as icon links in both the hero and the contact section.

## 🛠 Tech Stack

- **HTML5 / CSS3** — custom properties (design tokens), CSS Grid & Flexbox, no CSS framework
- **Vanilla JavaScript** — no dependencies, no bundler
- **Canvas API** — waveform/bar hero animation
- **SVG** — signal tower graphic, social icons
- **Google Fonts** — [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)

## 🚀 Running Locally

No build tools required — it's a static site.

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
```

Then just open `index.html` in a browser, or serve it locally:

```bash
python3 -m http.server 8080
# visit http://localhost:8080
```

## 🎨 Customization

- **Colors / fonts** — edit the `:root` design tokens at the top of `style.css` (`--bg`, `--amber`, `--teal`, `--font-display`, etc.).
- **Content** — all copy lives directly in `index.html`; timeline, project cards and skill bars are plain markup blocks you can duplicate.
- **Skill levels** — set via `data-level="1–5"` on `.bars` elements; the bar UI is generated by `script.js`.
- **Loader name** — change the `name` constant in the loader IIFE at the top of `script.js`.
